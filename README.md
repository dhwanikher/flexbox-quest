# Flexbox Quest 🎮

**Assignment 02 — Scaler WebDev 101 | Group C**

A **Mini Game UI** built entirely with HTML5 and CSS Flexbox — no JavaScript, no CSS Grid, no frameworks.

---

## What's Built

| Section | Description |
|---------|-------------|
| **Part 2 — Display Demo** | Experiment comparing `block`, `inline-block`, and `flex` with written answers |
| **Game Header** | Flexbox `space-between` bar with title, stats (Lives · Coins · Level), Pause & Menu buttons |
| **Game Area** | Three Flexbox rows showing Player, Star, and 3 Platforms in a styled game canvas |
| **Controls Panel** | 3×3 D-pad grid + extra action buttons, all Flexbox |
| **Inventory Panel** | 12-slot grid using `flex-wrap` with filled/empty slot states |
| **Quest Panel** | Ordered quest list with done / active / pending states + progress bar |
| **Footer** | Branded Flexbox footer with credit and copyright |

---

## Rules Compliance

- ✅ HTML + CSS only
- ✅ Flexbox for **all** layout
- ✅ **No** CSS Grid
- ✅ **No** `position: absolute` or `position: fixed`
- ✅ **No** JavaScript
- ✅ **No** Bootstrap / Tailwind / frameworks
- ✅ **No** random margins to force position
- ✅ Responsive (768px + 480px breakpoints)
- ✅ `prefers-reduced-motion` supported
- ✅ Semantic HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`)
