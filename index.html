Observations & Answers

  1. Default <div>: display: block. Takes full width, starts on a new line, supports margin/padding on all sides.
  2. Default <span>: display: inline. Only as wide as content, sits on the same line, top/bottom margin has no effect.
  3. inline-block: Sits on the same line like inline, but respects width, height, and full box model like block.
  4. display: flex: Turns the container into a flex container; children (flex items) line up horizontally by default, and you gain access to justify-content, align-items, gap, etc.
